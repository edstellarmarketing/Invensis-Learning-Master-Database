01 Prerequisites

A short checklist before you start. Everything here is free.

  • Node.js 18.18+ (Node 20 or 22 recommended) and npm.
  • A GitHub account with access to the edstellarmarketing repository.
  • A Vercel account (sign in with GitHub, free Hobby plan is enough).
  • Optional: an Anthropic and/or Groq API key for AI Search.
✓

The app runs with zero keys. Keys only unlock two extras: saving on Vercel (database) and AI-assisted company research. Browsing, seed data, CSV import, and manual editing work without any.

02 Run it locally

Clone, install, and start the dev server. Locally the app reads and writes the JSON files in src/data/, no database needed.

# clone and enter
git clone https://github.com/edstellarmarketing/Invensis-Learning-Master-Database.git
cd Invensis-Learning-Master-Database

# install dependencies
npm install

# optional: create a local env file for AI keys
cp .env.example .env.local

# start the dev server → http://localhost:3000
npm run dev

Other useful commands

npm run build   # production build
npm run lint    # eslint
npm test        # unit tests (CSV parser)

03 Environment variables

The complete list. In Vercel these go under Project → Settings → Environment Variables; locally they live in .env.local.

VariableStatusWhat it does
UPSTASH_REDIS_REST_URL Prod save Database endpoint. Auto-added by the Upstash integration. Required to save on Vercel.
UPSTASH_REDIS_REST_TOKEN Prod save Database auth token. Auto-added by the Upstash integration.
KV_REST_API_URL Alt Accepted alternative name, Vercel's Upstash integration may inject this instead. The app reads either pair.
KV_REST_API_TOKEN Alt Alternative token name, paired with KV_REST_API_URL.
ANTHROPIC_API_KEY Optional Enables AI Search via Claude (web search). Must be a real Anthropic key, starts sk-ant-. Paid Anthropic usage.
ANTHROPIC_MODEL Optional Override the Claude model. Defaults to claude-sonnet-5.
OPENROUTER_API_KEY Optional AI Search via OpenRouter. Use this (not ANTHROPIC_API_KEY) if your key starts sk-or-v1-. Anthropic rejects OpenRouter keys with a 401.
OPENROUTER_MODEL Optional Defaults to anthropic/claude-3.5-sonnet:online (paid, live web search via OpenRouter's plugin). Swap for any :free model slug from openrouter.ai/models for $0 cost, no live search.
GROQ_API_KEY Optional AI Search fallback via Groq. Free tier at console.groq.com. Used when neither Claude nor OpenRouter keys are set, or "Groq" is picked in the UI.
GROQ_MODEL Optional Override the Groq model. Defaults to llama-3.3-70b-versatile (no live browsing, but reliable on the free tier; groq/compound has web search but exhausts the free rate limit on a single request).
!

You never type the two Upstash values by hand, connecting the integration in step 05 injects them automatically. The two API keys are the only ones you add manually.

04 Deploy to Vercel

Import the repo. The framework, build command, and output are auto-detected (Next.js).

  1. Import the project

    Vercel dashboard → Add New → Project → pick the Invensis-Learning-Master-Database repo → Import.

  2. Keep the defaults

    Framework Next.js, build next build, install npm install. No changes needed.

  3. Deploy

    Click Deploy. The first build ships with the seed data baked in, so the site is browsable immediately, saving is switched on in the next step.

05 Connect the database (required to save)

Vercel's filesystem is read-only, so writes need a database. Upstash Redis (free) stores both datasets and makes every edit, CSV import, and bulk action work in production.

  1. Open Storage

    Project → Storage tab → Create Database.

  2. Choose Upstash → Redis

    Under Marketplace Database Providers pick Upstash, then Redis, then the Free plan. Do not pick "Redis (Official Redis for Vercel)", different product, different variable names.

  3. Leave the prefix empty

    On the connect screen, keep Production and Preview checked and leave Custom Prefix blank. A prefix would rename the variables and the app wouldn't find them.

  4. Connect & redeploy

    Connect to Project injects the Upstash variables. Then Deployments → ⋯ → Redeploy so they take effect.

!

Once the database is live, edits made on the site are stored in Redis, not in the repo's JSON files. Use Export JSON on the dashboard for backups. On first run the database is auto-seeded from the bundled data.

06 Enable AI Search

Optional. Adds "AI Search" to the companies table, it finds up to 100 real companies per industry with annual-report links and training insights. Three providers, selectable in the UI.

  1. Get a key

    Groq (free) at console.groq.com, Anthropic (paid, direct Claude) at console.anthropic.com, or OpenRouter (paid, many models incl. Claude) at openrouter.ai.

  2. Match the key to the right variable

    An Anthropic key starts sk-ant- → use ANTHROPIC_API_KEY. An OpenRouter key starts sk-or-v1- → use OPENROUTER_API_KEY instead. Putting an OpenRouter key into ANTHROPIC_API_KEY fails with a 401 "invalid x-api-key" error.

  3. Add it in Vercel

    Settings → Environment Variables → add the matching variable(s) → scope to Production → Save.

  4. Redeploy

    Env changes require a redeploy. After that, the provider dropdown offers Auto (Claude, then OpenRouter, then Groq), or any one directly.

$

Claude and OpenRouter's default model (:online) are paid per search (web search + tokens) and give live-verified results. Groq's free tier is $0 but answers from model knowledge only, results are marked "Likely:" for you to verify. Already-saved companies are excluded automatically so repeat searches keep finding new prospects.

07 Geographic discovery (free, no key)

A local script finds companies by industry and city via OpenStreetMap and writes a CSV in the app's import format. Load it with the Import CSV button on any course × industry table.

# names + websites for IT companies in Bengaluru
node scripts/discover-companies.mjs --industry it --city "Bengaluru" --country India

# see all options and industry presets
node scripts/discover-companies.mjs --help

Presets: it, software, construction, healthcare, bfsi, logistics, manufacturing, telecom, education, energy. Then run AI Search on the same industry to backfill annual reports and insights.

08 Verify the deploy

Open your Vercel URL and confirm each works. All of these were tested green on production.

✓Dashboard loads with stat cards and research coverage.
✓Add a company, refresh, it persists (database is connected).
✓Import a CSV, then bulk-select and delete rows.
✓Edit and delete industries via the "Manage" toggle.

✓AI Search returns candidates (only if a key is set).

09 Troubleshooting

"This deployment has a read-only filesystem…"

The database isn't connected (or you didn't redeploy after connecting). Do step 05, then redeploy.

Saves work but an old deployment still errors

You're viewing a cached/previous deployment. Open the latest one from the Deployments tab, or hard-refresh.

AI Search says "disabled"

No provider key is set. Add GROQ_API_KEY, ANTHROPIC_API_KEY, or OPENROUTER_API_KEY and redeploy (step 06).

Claude provider returns "401 invalid x-api-key"

The value in ANTHROPIC_API_KEY is not a real Anthropic key, the most common cause is pasting an OpenRouter key (starts sk-or-v1-) there instead. Move it to OPENROUTER_API_KEY and pick "OpenRouter" in the provider dropdown, or get a genuine key at console.anthropic.com.

Discovery script returns nothing

The city name must match OpenStreetMap's area label. Try a different spelling, another preset, or a raw --tag key=value filter.

Large AI searches time out

Counts of 50–100 take a few minutes. The route allows up to 300s; if your Vercel plan caps function duration lower, request fewer companies per search.
